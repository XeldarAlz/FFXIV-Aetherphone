## これは何か

Aetherphone は、FINAL FANTASY XIV の画面上に本物のスマートフォンを置く、無料でオープンソースの Dalamud プラグインです。ホーム画面、アプリスイッチャー、通知、着信音、テーマ変更できる壁紙を備えた、ドッキングされ常時表示されるデバイスです。アプリの背後では Aetherphone ユーザー向けの独自のソーシャルネットワークが動作しており、ローカルだけでなくキャラクターやセッションをまたいで機能します。

プライバシーと安全性を最優先しています。テキストメッセージ・添付ファイル・ボイスメモはエンドツーエンドで暗号化され、通話は通信経路上で暗号化されます。投稿と画像は明確なコンテンツルールのもとで人間のモデレーションチームが確認します。

## ハイライト

- **ソーシャル**：マイクロブログ、写真フィード、ボイスメモとグループ通話に対応したプライベートメッセージ、そして任意の 18+ コンパニオンアプリ。
- **ゲームチャット**：ゲーム内のすべてのチャットチャンネルをスマホに。タブは自由に組み合わせられ、Tell は独立した会話として届きます。
- **ツール**：マーケットボードのトラッカー、ハウジングブラウザー、会場・イベントの一覧、ライブコミュニティラジオ局と Rolladeck DJ リストを含むゲーム内ミュージック、天気、ウォレット、タイマーとリセット、フォトライブラリとカメラ、ショートカット、そしてミニゲームのポケットアーケードなど、40 のアプリ。
- **一緒に視聴**：YouTube を含む動画をゲーム内のスクリーンに映し、一緒に見ている全員の再生を同期します。ローカルファイルにも対応：視聴者はそれぞれ自分のコピーを選んで同期できます。
- **カジノ**：プレイマネーで遊ぶブラックジャック、スロット、スクラッチカード、共用のホイール、ビンゴ。現実のお金は関わらず、何も換金価値を持ちません。
- **自分好みに**：好きなアクセントカラー、壁紙、Lodestone のキャラクターポートレート、カスタム着信音、控えめな操作音、文字サイズのズーム、そして好きな大きさにドラッグできるスマホ。最小化中は、選んだ項目だけを好きな並び順で表示します：時計、日付、再生中、通話、通知カード、未読バッジ、さらにエオルゼア時間、天候、次のリセット、ギル、Aether Coin、リテイナー探索、アクティビティリングのウィジェット。

機能の全ツアー、スクリーンショット、詳細はウェブサイトでご覧いただけます。

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## インストール

ゲーム内で：`/xlsettings` → **Experimental** → **Custom Plugin Repositories** に貼り付け：

```
https://raw.githubusercontent.com/XeldarAlz/DalamudPlugins/main/repo.json
```

**Enabled** にチェックを入れ、**+** をクリックし、**Save and Close** を押します。`/xlplugins` → **All Plugins** を開き、**Aetherphone** を検索してインストールします。

中国版でプレイしていますか？電話がそれを検出し、そこで利用できないアプリ（Music、AetherStream、News）を非表示にして、Lodestone の代わりに Rising Stones（石之家）のプロフィールでサインインします。

## コマンド

| コマンド | 動作 |
|---|---|
| `/phone` | 電話の表示を切り替える |
| `/aetherphone` | `/phone` のエイリアス |
| `/phone run <name>` | ショートカットを名前で実行する（ホットバーのマクロに置けるように） |
| `/phone market [item]` | マーケットボードを開き、アイテム名を指定すればそれを検索する |
| `/phone reset` | 電話を画面中央に戻す |
| `/phone test` | サンプル通知を送る |

## 法的事項

オンライン機能を使用することは、利用規約への同意を意味します。プライバシーポリシーは Aethernet サービスがあなたのデータをどう扱うかを説明します。オフライン機能はあなたのマシン内にとどまりますが、一部のアプリは公開されているゲームデータをサードパーティのサービスから直接取得しており、これもポリシーの対象です。
