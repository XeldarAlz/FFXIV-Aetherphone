## 这是什么

Aetherphone 是一款免费、开源的 Dalamud 插件，在 FINAL FANTASY XIV 中把一部真正的智能手机搬上屏幕：一台停靠、常驻显示的设备，配有主屏幕、应用切换器、通知、铃声以及可换主题的壁纸。应用背后运行着一个面向 Aetherphone 用户的社交网络，因此它们可以跨角色、跨会话工作，而不仅限于本地。

隐私与安全至上：文字消息、附件与语音留言端到端加密，通话在传输中加密；帖子与图片由人工审核团队依照明确的内容规则进行审核。

## 亮点

- **社交**：微博、照片信息流、支持语音留言与群组通话的私密消息，以及一款可选的 18+ 伴侣应用。
- **游戏聊天**：把游戏里的所有聊天频道搬上手机，标签页由你自由组合，悄悄话则是独立的会话。
- **实用工具**：市场板追踪、房屋浏览器、场所与活动目录、含实时社区电台和 Rolladeck DJ 列表的游戏内音乐、天气、钱包、计时器与重置、照片库与相机、快捷指令，还有一座掌上小游戏街机，尽在 40 款应用之中。
- **一起观看**：把视频（包括 YouTube）投射到游戏内的屏幕上，并为一起观看的人同步播放进度。本地文件同样支持：每位观众选择自己的文件副本即可保持同步。
- **赌场**：游戏币玩法的二十一点、老虎机、刮刮卡、公共转盘和宾果。不涉及真实货币，任何东西都没有现金价值。
- **专属于你**：任意强调色、壁纸、Lodestone 角色立绘、自定义铃声、轻巧的界面音效、文字大小缩放，以及可以随意拖拽大小的手机。最小化时只显示你挑选的内容，顺序也由你决定：时钟、日期、正在播放、通话、通知卡片、未读标记，以及艾欧泽亚时间、天气、下次重置、金币、Aether Coin、雇员探险和活跃度圆环等小组件。

完整的功能介绍、截图与细节都在官网：

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## 安装

在游戏中：`/xlsettings` → **Experimental** → 粘贴到 **Custom Plugin Repositories**：

```
https://raw.githubusercontent.com/XeldarAlz/DalamudPlugins/main/repo.json
```

勾选 **Enabled**，点击 **+**，然后点击 **Save and Close**。打开 `/xlplugins` → **All Plugins**，搜索 **Aetherphone** 并安装。

在玩中国版客户端？手机会自动检测，隐藏在那里不可用的应用（Music、AetherStream 和 News），并改为通过你的石之家（Rising Stones）个人资料登录，而不是 Lodestone。

## 指令

| 指令 | 作用 |
|---|---|
| `/phone` | 切换手机显示 |
| `/aetherphone` | `/phone` 的别名 |
| `/phone run <name>` | 按名称运行快捷指令，方便挂在热键栏宏上 |
| `/phone market [item]` | 打开市场板，若给出物品名则直接搜索 |
| `/phone reset` | 将手机重新居中于屏幕 |
| `/phone test` | 发送一条示例通知 |
