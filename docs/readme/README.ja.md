## ポケットの中のスマホと同じ作り

**HUD に溶け込む。** 好きな場所へドラッグし、サイズを変え、時計やウィジェット、音楽、通話を表示するミニ電話に縮めることもできます。

**ウィジェットとスマートスタック。** ほとんどのアプリにウィジェットがあり、角をつまんでサイズを変え、重ねてドロップすればスタックになります。

**Dynamic Island** が、通話、再生、タイマー、航海、ウォッチパーティー、集まりの状況をお知らせします。

**Spotlight とコントロールセンター。** ホーム画面を下に引けばアプリ、連絡先、設定、メモ、マーケットのアイテムを検索でき、画面の上部をタップすれば音楽、音量、明るさ、おやすみモードを操作できます。

**自分だけの一台に。** 壁紙、アクセントカラー、アイコンの見た目、スマホケース、ホーム画面のレイアウトをルックとして保存でき、キャラクターごとに切り替わります。

**あなたの言語で。** 9つのインターフェース言語に対応し、投稿、プロフィール、メッセージはワンタップで翻訳できます。

**プライバシーを第一に。** メッセージ、写真、ボイスメッセージはエンドツーエンドで暗号化されます。Velvet の自己紹介はプレーンテキストで送信されます。報告されたコンテンツは、人によるモデレーションチームが確認します。

## インストール

ゲーム内で：`/xlsettings` → **Experimental** → **Custom Plugin Repositories** に貼り付け：

```
https://aetherphone.net/repo.json
```

**Enabled** にチェックを入れ、**+** をクリックし、**Save and Close** を押します。`/xlplugins` → **All Plugins** を開き、**Aetherphone** を検索してインストールします。`/phone` と入力すれば、スマホを手に取れます。

中国版でプレイしていますか？ 電話がそれを検出し、代わりに Rising Stones（石之家）のプロフィールでサインインします。

<details>
<summary><strong>コマンド</strong></summary>

| コマンド | 動作 |
|---|---|
| `/phone` | 電話の表示を切り替える |
| `/aetherphone` | `/phone` のエイリアス |
| `/phone run <name>` | ショートカットを名前で実行する（ホットバーのマクロに置けます） |
| `/phone market [item]` | マーケットボードを開き、アイテム名を指定すればそれを検索する |
| `/phone reset` | 電話を画面中央に戻す |
| `/phone test` | サンプル通知を送る |

</details>

## AI の利用について

Aetherphone は AI コーディングツールを使って開発されており、[Dalamud の AI ポリシー](https://dalamud.dev/plugin-publishing/ai-policy/)における **Copilot** レベルを宣言しています。実装の大部分は AI が担い、仕様の作成、すべての変更のレビュー、ゲーム内でのテスト、そして結果への責任は人が持ちます。

**目に見えるもの、耳に聞こえるものに AI 生成物はありません。** アイコン、壁紙、スマホケース、サウンド、着信音、フォントはすべて、オリジナル、クレジットされたアーティストによる作品、またはライセンスを受けた素材のいずれかです。英語のテキストは人の手で書かれ、ほかの8言語は AI の支援を受けた翻訳を人がレビューしています。

**あなたのコンテンツは、あなたのもの。** 翻訳機能が送信するのは、あなたが翻訳を求めたテキストと、自動翻訳をオンにしたフィードやチャットだけです。Aethernet のモデレーションに AI は使われておらず、あなたの投稿やメッセージが AI モデルの学習に使われることは一切ありません。

→ [AI の利用について](../ai-usage.md) · [サードパーティ通知](../../THIRD-PARTY-NOTICES.md)
