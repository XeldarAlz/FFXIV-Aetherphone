## これは何か

Aetherphone は FINAL FANTASY XIV で唯一、本当に動作する初めての電話プラグインです。ホーム画面、アプリスイッチャー、通知を備えた、常時表示のドッキング端末として動きます。アプリの裏側では専用のソーシャルネットワークが動いているので、投稿したもの、送ったもの、保存したものはローカルに留まらず、キャラクター、ワールド、セッションをまたいで引き継がれます。

## ハイライト

- **HUD に溶け込む電話。** 好きな場所へドラッグし、好きな大きさに変え、選んだウィジェットだけを表示する帯に最小化できます。リアルタイムのエリアミニマップに畳んで、ゲーム本体のミニマップの代わりにすることもできます。
- **ワールドを問わず誰にでも送れる。** ChocoChat はワールドもデータセンターも問わず、Aetherphone を使っているすべての人に届きます。ボイスメッセージ、グループチャット、連絡先からそのまま発信できる音声通話つき。パーティも、フレンドリストも、移動も要りません。
- **自分たちのソーシャルアプリ。** 短文投稿のチャーパー、写真のエーテルグラム、任意で使える 18+ の Velvet。ひとつのアカウントがすべてに共通し、キャラクターを変えても付いてきます。
- **ゲーム内チャットを丸ごと再構成。** Linkpearl はゲームのチャット全チャンネルを自分で組んだタブにまとめ、テルは個別の会話として扱い、チャンネルごとに色を分け、ゲームでは切れてしまう長文も分割して送信間隔を調整します。
- **電話を閉じたままチャット。** どの会話もフローティングウィンドウに切り出せて、ウィンドウ同士をタブに統合でき、戦闘中やコンテンツ中は自動で隠れて終わったら自分で戻ってきます。
- **プレイに寄り添うアプリ。** 各ギミックで自分の担当位置が示される Strats のレイド攻略、マークとトレインのハント、海洋探索の釣り、さらにマーケットボード、ハウジング、マップ、Venues (会場)、日課、コレクション、インベントリ。
- **日常の道具もひと通り。** メモ、カレンダー、リセットとリテイナー用のタイマー、電卓、ウォレット、カメラと写真、時計、天気予報、そしてホットバーのマクロから起動できるショートカット。
- **一緒に観て、一緒に聴く。** MogCast はゲーム世界のスクリーンに映像を映し、その場の全員で再生を同期します。ミュージックはコミュニティのライブラジオ局と Rolladeck の DJ セットをゲーム内に届けます。
- **あなたの言語で読める。** 投稿、プロフィール、プライベートメッセージはワンタップで翻訳でき、フィードもチャットも届いたそばから自動で翻訳できます。
- **息抜きも中に。** Gamba は遊び用チップのカジノで、ブラックジャック、スロット、スクラッチ、ビンゴ、みんなで回すホイールがあり、換金価値は一切ありません。ゲームは Doom を含む三十本以上のアーケードで、ウノ、チェス、ビリヤードは友達とオンラインで遊べます。
- **自分好みに。** 好きな壁紙、自分で用意した着信音と通知音、任意のアクセントカラー、Lodestone のキャラクター立ち絵、控えめな UI サウンド、文字サイズのズーム。
- **設計からプライベート。** メッセージ、添付ファイル、ボイスメッセージはエンドツーエンドで暗号化され、通話は転送中に暗号化され、公開の投稿と画像は人によるモデレーションチームが確認します。

アプリは全部で 42 本。機能の全ツアー、スクリーンショット、詳細はウェブサイトでご覧いただけます。

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## インストール

ゲーム内で：`/xlsettings` → **Experimental** → **Custom Plugin Repositories** に貼り付け：

```
https://aetherphone.net/repo.json
```

**Enabled** にチェックを入れ、**+** をクリックし、**Save and Close** を押します。`/xlplugins` → **All Plugins** を開き、**Aetherphone** を検索してインストールします。

中国版でプレイしていますか？電話がそれを検出し、Lodestone の代わりに Rising Stones（石之家）のプロフィールでサインインし、必要なアプリは中国版のワールドとニュースフィードを参照します。

## コマンド

| コマンド | 動作 |
|---|---|
| `/phone` | 電話の表示を切り替える |
| `/aetherphone` | `/phone` のエイリアス |
| `/phone run <name>` | ショートカットを名前で実行する（ホットバーのマクロに置けるように） |
| `/phone market [item]` | マーケットボードを開き、アイテム名を指定すればそれを検索する |
| `/phone reset` | 電話を画面中央に戻す |
| `/phone test` | サンプル通知を送る |

## 法的事項

オンライン機能を使用することは、利用規約への同意を意味します。プライバシーポリシーは Aethernet サービスがあなたのデータをどう扱うかを説明します。オフライン機能はあなたのマシン内にとどまりますが、一部のアプリは公開されているゲームデータをサードパーティのサービスから直接取得しており、これもポリシーの対象です。
