## 这是什么

Aetherphone 是一款 FINAL FANTASY XIV 手机插件：一台停靠在屏幕上的设备，配有主屏幕、应用切换器和通知。它的在线应用运行在插件专属的在线服务 Aethernet 上，所以你发布、发送和保存的内容会存储在你的 Aethernet 账号中，而不只是留在本机。默认情况下，每个角色都用自己的账号登录；通过一项设置，也可以让你选定的一个账号在所有角色上保持登录。

## 亮点

- **长在界面里的手机。** 想放哪就拖到哪，大小随你调，还能最小化成迷你手机，只显示你挑选的小组件，并像完整手机一样从角落调整大小。它还能收起成实时的区域小地图，你可以把它放在游戏小地图所在的位置。
- **与任何服务器的玩家发消息。** 只要你和对方互相保存了号码，ChocoChat 就能跨服务器、跨大区使用，支持语音留言、群聊，以及从联系人发起的语音通话。无需组队、加好友或跨服。
- **属于你们的社交应用。** 发短帖的 Chirper（叽叽）、发照片的 Aethergram（以太图集），以及可选的 18+ 空间 Velvet，拉拉菲尔角色无法使用 Velvet。一个 Aethernet 账号即可登录这三款应用，每款应用还可以有各自的显示名称和用户名。
- **游戏内每个聊天频道，重新编排。** Linkpearl 把游戏聊天的所有频道收进你自己搭建的标签页，悄悄话独立成会话，每个频道可单独配色，输入框还会把游戏会截断的长消息拆开并按节奏发出。每个标签页都可以按日志或聊天气泡阅读，你可以选择聊天主题和壁纸、导入游戏的频道颜色，并在截图时隐藏名字。
- **手机关着也能聊。** 把任意会话弹出成悬浮窗，它会出现在手机旁边；新的聊天可以作为标签页加入其中，还能让它在战斗和副本中自动隐藏，之后自己回来。
- **陪你一起玩的应用。** 每个机制都标出你站位的 Strats 副本攻略、追踪狩猎目标与狩猎车队的狩猎、出海垂钓的捕鱼，还有市场、房屋、地图、场馆、日常、收藏馆和物品栏。
- **日常小工具也齐全。** 备忘录、可自建日程分组和提醒的日历、管重置与雇员的计时器、计算器、钱包、可自建相簿并内置照片编辑器的相机与照片、时钟、看天气的 Skywatcher（天气预报），以及可以挂到热键栏宏上触发的快捷指令。
- **一起看，一起听。** MogCast（莫古影院）可以在手机上或你放置在世界中的屏幕上播放视频，并为加入你一起看的附近 Aetherphone 用户同步播放。音乐可以播放社区电台、网络电台和你搜索的歌曲，并列出正在直播的 Rolladeck DJ。
- **说你的语言。** 帖子、个人资料和私信都能一键翻译，信息流和聊天还可以在新帖子和新消息抵达时自动翻译。翻译由 Aethernet 完成，私信的翻译绝不会被存储。
- **闲下来也有得玩。** Gamba（以太赌场）是使用游戏币的赌场，有二十一点、老虎机、刮刮卡、宾果和一个公共转盘，其中任何东西都没有现金价值。游戏则是一间收录三十款作品的街机厅，Doom 也在其中，另有 Uno、国际象棋和八球台球可与好友在线对战。
- **打造成你的样子。** 自定义壁纸、自己的铃声和通知音、任意强调色、Lodestone 角色立绘、轻巧的界面音效，以及文字大小缩放。可以把整套设置保存为一个外观方案，每个角色各自保留自己的方案：主屏幕会随你登录的角色切换。
- **加密与审核。** 消息、照片和语音留言均采用端到端加密，密钥由手机自动创建。举报或翻译一条消息时，其文字会以可读形式发送给 Aethernet。通话在传输中加密，并经由 Aethernet 服务器中转，不是端到端加密。人工审核团队会审核被举报的帖子、图片和消息。

共 42 款应用。完整的功能介绍、截图与细节都在官网：

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## 安装

在游戏中：`/xlsettings` → **Experimental** → 粘贴到 **Custom Plugin Repositories**：

```
https://aetherphone.net/repo.json
```

勾选 **Enabled**，点击 **+**，然后点击 **Save and Close**。打开 `/xlplugins` → **All Plugins**，搜索 **Aetherphone** 并安装。

在玩中国版客户端？手机会自动检测，改为通过你的石之家（Rising Stones）个人资料登录而不是 Lodestone，并让需要的应用使用国服的服务器列表和新闻源。

## 指令

| 指令 | 作用 |
|---|---|
| `/phone` | 切换手机显示 |
| `/aetherphone` | `/phone` 的别名 |
| `/phone run <name>` | 按名称运行快捷指令，方便挂在热键栏宏上 |
| `/phone market [item]` | 打开市场板，若给出物品名则直接搜索 |
| `/phone reset` | 将手机重新居中于屏幕 |
| `/phone test` | 发送一条示例通知 |
