## 这是什么

Aetherphone 是 FINAL FANTASY XIV 上第一款也是唯一一款真正可用的手机插件：一台停靠在屏幕上、常驻显示的设备，配有主屏幕、应用切换器和通知。应用背后运行着专属的社交网络，所以你发布、发送和保存的内容不会只留在本机，而是跟着你跨角色、跨服务器、跨每一次登录。

## 亮点

- **长在界面里的手机。** 想放哪就拖到哪，大小随你调，最小化后只显示你挑选的小组件。它还能收起成实时的区域小地图，顶替游戏自带的小地图。
- **无论哪个服务器，都能发消息。** ChocoChat 可以联系到任何一位 Aetherphone 用户，不分服务器也不分大区，支持语音留言、群聊，以及直接从联系人发起的语音通话。不用组队，不用加好友，也不用跨服。
- **属于你们的社交应用。** 发短帖的叽叽、发照片的以太图集，以及可选的 18+ 伴侣应用 Velvet。一个身份通用于全部，换角色也跟着你。
- **游戏内每个聊天频道，重新编排。** Linkpearl 把游戏聊天的所有频道收进你自己搭建的标签页，悄悄话独立成会话，每个频道可单独配色，输入框还会把游戏放不下的长消息拆开并按节奏发出。
- **手机关着也能聊。** 把任意会话弹出成悬浮窗，把多个窗口合并成标签页，还能让它们在战斗和副本里自动隐藏、结束后自己回来。
- **陪你一起玩的应用。** 每个机制都标出你站位的 Strats 副本攻略、追踪狩猎点与狩猎车队的狩猎、出海远航的捕鱼，还有市场、房屋、地图、场馆、日常、收藏馆和物品栏。
- **日常小工具也齐全。** 备忘录、日历、管重置与雇员的计时器、计算器、钱包、相机与照片、时钟、看天气的天气预报，以及可以挂到技能栏宏上触发的快捷指令。
- **一起看，一起听。** 莫古影院把视频投到游戏世界里的屏幕上，并为在场的每个人同步播放；音乐则把社区电台直播和 Rolladeck 的 DJ 歌单带进游戏。
- **说你的语言。** 帖子、个人资料和私信都能一键翻译，信息流和聊天还可以在消息抵达时自动翻译。
- **闲下来也有得玩。** 以太赌场是游戏币玩法的赌场，有二十一点、老虎机、刮刮卡、宾果和一个公共转盘，其中任何东西都没有现金价值。游戏则是一间三十多款作品的街机厅，Doom 也在里面，还能和朋友在线玩 UNO、国际象棋和台球。
- **打造成你的样子。** 自定义壁纸、自己的铃声和通知音、任意强调色、Lodestone 角色立绘、轻巧的界面音效，以及文字大小缩放。
- **从设计上就注重隐私。** 消息、附件与语音留言端到端加密，通话在传输中加密，公开的帖子与图片由人工审核团队查看。

共 42 款应用。完整的功能介绍、截图与细节都在官网：

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## 安装

在游戏中：`/xlsettings` → **Experimental** → 粘贴到 **Custom Plugin Repositories**：

```
https://aetherphone.net/repo.json
```

勾选 **Enabled**，点击 **+**，然后点击 **Save and Close**。打开 `/xlplugins` → **All Plugins**，搜索 **Aetherphone** 并安装。

在玩中国版客户端？手机会自动检测，改为通过你的石之家（Rising Stones）个人资料登录而不是 Lodestone，并让需要的应用使用国服的服务器列表和新闻源。

## 指令

| 指令 | 作用 |
|---|---|
| `/phone` | 切换手机显示 |
| `/aetherphone` | `/phone` 的别名 |
| `/phone run <name>` | 按名称运行快捷指令，方便挂在热键栏宏上 |
| `/phone market [item]` | 打开市场板，若给出物品名则直接搜索 |
| `/phone reset` | 将手机重新居中于屏幕 |
| `/phone test` | 发送一条示例通知 |
