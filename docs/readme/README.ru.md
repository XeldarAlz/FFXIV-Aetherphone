## Что это такое

Aetherphone это первый и единственный полноценно работающий плагин-телефон для FINAL FANTASY XIV: закреплённое на экране устройство, которое всегда под рукой, с домашним экраном, переключателем приложений и уведомлениями. За приложениями работает собственная социальная сеть, поэтому всё, что вы публикуете, отправляете и сохраняете, остаётся с вами на любых персонажах, мирах и сессиях, а не только на вашем компьютере.

## Основные возможности

- **Телефон прямо в интерфейсе.** Перетащите его куда угодно, задайте любой размер и сверните в полоску, где видны только выбранные вами виджеты. Ещё он складывается в живую мини-карту зоны и может занять место игровой мини-карты.
- **Пишите кому угодно, в любом мире.** ChocoChat дотягивается до любого пользователя Aetherphone независимо от мира и дата-центра: голосовые сообщения, групповые чаты и голосовые звонки прямо из карточки контакта. Без пати, без списка друзей и без путешествий.
- **Свои социальные приложения.** Chirper для коротких записей, Aethergram для фотографий и Velvet, необязательное приложение 18+. Одна учётная запись работает во всех и переходит с персонажа на персонажа.
- **Весь игровой чат, собранный заново.** Linkpearl складывает все каналы игрового чата во вкладки, которые вы собираете сами: приваты становятся отдельными диалогами, у каждого канала свои цвета, а поле ввода делит и растягивает по времени сообщения, которые игра обрезала бы.
- **Переписка при закрытом телефоне.** Вынесите любой диалог в плавающее окно, объедините окна во вкладки и позвольте им прятаться в бою и в подземельях, а потом возвращаться самим.
- **Приложения, которые играют вместе с вами.** Strats с рейдовыми шпаргалками и вашей позицией на каждой механике, Охоты для меток и поездов, Рыбалка для океанских рейсов, а также Рынок, Housing, Карты, Заведения, Ежедневные, Коллекции и Инвентарь.
- **И повседневные мелочи.** Заметки, Календарь, Таймеры для ресетов и слуг, Калькулятор, Кошелёк, Камера и Фото, Часы, Погода и Быстрые команды, которые можно вызвать макросом с панели.
- **Смотрите и слушайте вместе.** MogCast выводит видео на экран прямо в игровом мире и синхронизирует воспроизведение для всех, кто рядом, а Музыка приносит в игру живые радиостанции сообщества и диджей-сеты Rolladeck.
- **Говорит на вашем языке.** Перевод в одно касание для записей, профилей и личных сообщений, а ленты и чаты умеют переводить всё сразу по мере поступления.
- **Есть чем занять себя.** Gamba это казино на игровые фишки: блэкджек, слоты, скретч-карты, бинго и общее колесо, и ничто из этого не имеет денежной ценности. Игры это аркадный зал из тридцати с лишним игр, включая Doom, плюс Уно, Шахматы и Бильярд онлайн с друзьями.
- **Сделайте его своим.** Свои обои, свои мелодии звонка и уведомлений, любой акцентный цвет, портреты персонажей с Lodestone, ненавязчивые звуки интерфейса и масштаб размера текста.
- **Приватность по умолчанию.** Сообщения, вложения и голосовые заметки шифруются от устройства к устройству, звонки шифруются при передаче, а публичные записи и изображения проверяет команда живых модераторов.

Всего 42 приложения. Полный обзор возможностей, скриншоты и подробности есть на сайте:

→ **[www.aetherphone.net](https://www.aetherphone.net/)**

## Установка

В игре: `/xlsettings` → **Experimental** → вставьте в **Custom Plugin Repositories**:

```
https://aetherphone.net/repo.json
```

Поставьте галочку **Enabled**, нажмите **+**, затем **Save and Close**. Откройте `/xlplugins` → **All Plugins**, найдите **Aetherphone** и установите.

Играете в китайскую версию игры? Телефон определяет её, выполняет вход через ваш профиль Rising Stones (石之家) вместо Lodestone и направляет приложения, которым это нужно, на китайские миры и китайскую ленту новостей.

## Команды

| Команда | Действие |
|---|---|
| `/phone` | Показать/скрыть телефон |
| `/aetherphone` | Псевдоним для `/phone` |
| `/phone run <name>` | Запустить быструю команду по имени, чтобы её можно было повесить на макрос хотбара |
| `/phone market [item]` | Открыть рыночную доску и найти предмет, если вы его укажете |
| `/phone reset` | Вернуть телефон в центр экрана |
| `/phone test` | Отправить пробное уведомление |

## Как внести вклад

Aetherphone имеет открытый исходный код, и вклад приветствуется. Начните с документации для разработчиков (на английском), затем прочитайте руководство по участию. Хотите вместо этого улучшить один из восьми переводов? Для этого не нужны ни код, ни сборка, ни git: руководство переводчика проведёт вас по всем шагам прямо в браузере.

→ [Документация для разработчиков](../README.md) · [Руководство по участию](../../CONTRIBUTING.md) · [Руководство переводчика](../translating.md)
